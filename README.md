# 🤖 CyberHelper

A powerful ChatGPT-like desktop application for Linux users, featuring multi-provider AI support with a beautiful, modern interface.

## ✨ Features

- 🎨 **ChatGPT-inspired UI/UX** - Familiar and intuitive interface
- 🔌 **Multi-Provider Support** - OpenAI, Anthropic Claude, Google Gemini, and more
- 🐧 **Native Linux Support** - Optimized for Kali Linux and all major distributions
- 💾 **Conversation History** - Save and resume your chats
- 🌓 **Dark/Light Mode** - Comfortable viewing in any environment
- ⚡ **Fast & Responsive** - Built with Electron for native performance
- 🔒 **Secure** - Your API keys are stored locally and encrypted
- 📝 **Markdown Support** - Rich text formatting with code syntax highlighting
- 💬 **Streaming Responses** - Real-time AI responses as they generate

## 🚀 Quick Install

### Debian/Ubuntu/Kali Linux
```bash
wget https://github.com/yourusername/cyberhelper/releases/latest/download/cyberhelper_amd64.deb
sudo dpkg -i cyberhelper_amd64.deb
```

### Arch Linux
```bash
yay -S cyberhelper
```

### Universal AppImage
```bash
wget https://github.com/yourusername/cyberhelper/releases/latest/download/cyberhelper.AppImage
chmod +x cyberhelper.AppImage
./cyberhelper.AppImage
```

### From Source
```bash
git clone https://github.com/yourusername/cyberhelper.git
cd cyberhelper
npm install
npm start
```

## 📋 System Requirements

- Linux (Kernel 3.10+)
- 4 GB RAM (8 GB recommended)
- 200 MB disk space
- Internet connection

## 🔑 Supported AI Providers

- **OpenAI** (GPT-4, GPT-3.5)
- **Anthropic Claude** (Claude 3.5 Sonnet, Claude 3 Opus)
- **Google Gemini** (Gemini Pro, Gemini Ultra)
- **Ollama** (Local models)
- **Custom OpenAI-compatible APIs**

## 🛠️ Development

```bash
# Install dependencies
npm install

# Run in development mode
npm run dev

# Build for production
npm run build

# Package for Linux
npm run package:linux
```
