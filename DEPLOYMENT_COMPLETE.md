## 📦 Installation Methods

### For Users:

1. **Quick Install Script**
   ```bash
   curl -fsSL https://raw.githubusercontent.com/thecnical/cyberhelper/main/install.sh | bash
   ```

2. **DEB Package** (Ubuntu/Debian/Kali)
   ```bash
   wget https://github.com/thecnical/cyberhelper/releases/latest/download/cyberhelper_amd64.deb
   sudo dpkg -i cyberhelper_amd64.deb
   ```

3. **AppImage** (Universal)
   ```bash
   wget https://github.com/thecnical/cyberhelper/releases/latest/download/cyberhelper.AppImage
   chmod +x cyberhelper.AppImage
   ./cyberhelper.AppImage
   ```

### For Developers:

```bash
# Clone repository
git clone https://github.com/thecnical/cyberhelper.git
cd cyberhelper

# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
npm run build:electron

# Package for Linux
npm run package:linux
```

## 🎯 How to Use

### Step 1: Launch Application
```bash
cyberhelper
```

### Step 2: Configure a Provider

#### Option A: Free Providers (No API Key Needed! 🆓)

1. Click Settings (⚙️)
2. Go to "AI Providers"
3. Enable any FREE provider:
   - **Groq** (Ultra fast!)
   - **OpenRouter** (Multiple models)
   - **APMix** (GPT-4o, Claude, Gemini)
   - **ApiNex** (GPT-4 Turbo, Claude Opus)
   - **ByteX, LLM7, FreeAI, Zenmux**
4. Most free providers have API key pre-filled as "free"
5. Just enable and start chatting!

#### Option B: Paid Providers (Better Quality)

1. **OpenAI**
   - Get API key: https://platform.openai.com/api-keys
   - Paste in Settings

2. **Anthropic Claude**
   - Get API key: https://console.anthropic.com/
   - Paste in Settings

3. **Google Gemini**
   - Get API key: https://makersuite.google.com/app/apikey
   - Paste in Settings

### Step 3: Start Chatting!

1. Click "New chat"
2. Select your provider from dropdown
3. Type your message
4. Press Enter
5. Enjoy AI responses!
