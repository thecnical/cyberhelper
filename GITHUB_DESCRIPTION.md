## Long Description
```
CyberHelper is a powerful, privacy-focused AI chat assistant built specifically for Linux users. 

With support for 13 AI providers including 8 completely FREE options (Groq, OpenRouter, APMix, 
ApiNex, ByteX, LLM7, FreeAI, Zenmux), you can access premium AI models like GPT-4, Claude 3.5 
Sonnet, and Gemini Pro without spending a dime or sharing personal data.

Features:
• ChatGPT-quality interface with exact UI/UX matching
• 8 FREE AI providers with no API key required
• Premium providers: OpenAI, Anthropic Claude, Google Gemini, Ollama
• Real-time streaming responses
• Markdown & code syntax highlighting (100+ languages)
• Dark/Light theme support
• Encrypted local storage
• No telemetry or tracking
• One-command installation
• Native Electron desktop app
• Optimized for Ubuntu, Kali, Debian, Arch, Fedora

Perfect for:
• Developers who need AI coding assistance
• Security researchers using Kali Linux
• Privacy-conscious users
• Students and learners
• Anyone wanting free access to premium AI models

Technology Stack:
• Frontend: React 18, TypeScript, Zustand
• Desktop: Electron 33
• AI SDKs: OpenAI, Anthropic, Google Generative AI
• Build: Vite, electron-builder

Get started in 3 commands:
git clone https://github.com/thecnical/cyberhelper.git
cd cyberhelper
chmod +x setup.sh && ./setup.sh

100% Free • 100% Open Source • 100% Privacy
```
